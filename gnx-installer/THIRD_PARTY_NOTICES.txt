GNX installer: third-party software

The GNX installer executable (GNX_v<version>.exe) is built from the Go source in this folder.
It contains the Go runtime and standard library and the Go modules listed below; their licenses follow.
It contains no UndertaleModTool code: UndertaleModCLI (GPL-3.0) is only run while building, to patch
data.win, and the installer ships the resulting binary diff (deltas/*.fossil).
