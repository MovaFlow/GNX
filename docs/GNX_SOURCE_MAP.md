# GNX source map

Where GNX's own GML lives (`GNX/gml/`, shipped as patches in `GNX/diffs/`). Generated by `python tools/source_map.py`; do not edit by hand.

Until October 2026 almost all of GNX lived in one file, `gml_GlobalScript_s_initials.gml` (27,000 lines). It now holds only the game's start-up (`scr_create_initials`, vanilla plus GNX's boot steps); every GNX function moved, unchanged, into one file per topic below. GML functions are global, so nothing calls them differently. GNX's changes inside vanilla files (hooks in `s_slot_state`, `s_mon_data`, `s_button_activate`, ...) did not move: see the patches in `GNX/diffs/`.
